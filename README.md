# DiveCheck for Linux

Built Linux releases of **DiveCheck by Kraken DiveWorks**, a scuba logbook with
gear service tracking, checklists and gas blending tools. This repository holds
only the finished app files that the Flathub package downloads, and the store
screenshots. The source code is not public.

- Install from Flathub: <https://flathub.org/apps/com.krakendiveworks.divecheck>
- About DiveCheck: <https://krakendiveworks.com/divecheck-app/>
- Help: <https://krakendiveworks.com/divecheck-support/>

DiveCheck needs a subscription, bought in the DiveCheck app on an iPhone, iPad,
Mac or Android phone. On Linux you sign in with the same account to unlock it.
